Why can't it reach the live site?

Best option: upload this HTML file to the Source Shark WordPress site (for example via Media or the theme folder) and open it from there. Same-domain requests always work.

Or allow cross-site reads of the public product feed by adding this to the theme's functions.php:

add_filter('rest_pre_serve_request', function($v){ header('Access-Control-Allow-Origin: *'); return $v; });
